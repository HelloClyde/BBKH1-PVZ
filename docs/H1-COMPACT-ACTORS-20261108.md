# 离线动画体积优化

以下为全量烘焙实验的历史记录，337 MB 动画及 494 MB 资源包已撤出默认
安装。当前方案见 [按真机热点选择离线动画](H1-SELECTIVE-ANIMATIONS-20261108.md)。

新增 90 类动画、18,000 个半帧的开发资源从 467,085,543 字节降到
337,471,394 字节，减少 129,614,149 字节（27.75%）。整套资源由
623,423,687 字节降到 493,809,538 字节。此处统计安装后的文件大小，
不以压缩安装包的体积代替。

| 动画 | 原字节数 | 优化后字节数 |
| --- | ---: | ---: |
| Boss | 167,316,841 | 128,427,284 |
| 片尾第一段 | 57,245,837 | 35,363,986 |
| 片尾第二段 | 46,792,772 | 28,463,424 |
| 片尾第三段 | 70,476,944 | 33,613,499 |
| 戴夫 | 28,721,317 | 22,116,879 |

空间主要用在大量已经光栅化的动画帧，而不是高分辨率源图片。新编码
把每条轨道的像素按 32×16 分块，完全相同的块只存一次；其余块与相邻
帧做有界差分，再压缩颜色字节。块内的位移和压缩选择在电脑上计算。
游戏只读取当前可见块并解码，不执行资源 CRC、内容哈希或完整帧预检。
保留原有 32 位颜色值、全部半帧、轨道可见性和每个像素的混合顺序。

打包器逐类选择文件至少缩小 10% 的新编码，共 32 类；其他 58 类继续
使用更小的原离线编码。两种文件均为完成光栅化的帧，运行时不存在因
这个选择而回到原始软件绘图的分支。最大差分依赖深度为 3，解码块采用
有上限的缓存；动画删除、关卡退出和内存回收沿用正常的资源释放入口。

## 重建与证据

先用 `tools/pack_extra_actors.py` 生成常规离线帧，保留其原始着色器
捕获证明；再运行：

```powershell
python tools/compact_extra_actors.py --experimental-all
python tools/tests/test_extra_actor_replay.py --resources build/extra-actor-compact-resources --output build/extra-actor-compact-replay
python tools/tests/test_extra_actor_replay.py --resources build/extra-actor-compact-resources --output build/extra-actor-compact-page-stress --only-type 74 --page-slots 1
```

编码器回读全部 18,000 个半帧，逐一比较原像素操作及顺序。游戏生产
读取器通过 11,088 次整帧对照，覆盖 90 类动画、轨道隐藏、屏幕边缘及
不同背景；Boss 单页换页压力测试另外通过 126 次整帧对照。
证据入口在 `verification/compact-actors-20261108/`。

候选程序 `5e4bee60…` 在物理 H1 上实测第六关：预览约 23.33 FPS，
首次选项呈现 75 ms，用户堆峰值 19,935,530 字节，没有分配或解码失败。
新块读取器实际解码 173 块，累计复用 373 次；测试专用的压缩准备动画
实际绘制 33 次。该准备动画仅为触达新读取器的测试资源，最终整包仍
选择其更小的原离线编码。真机仅安装了启动、第六关所需的首批资源，
没有以这个结果宣称 Boss、片尾和完整资源包已真机验收。

这些测试覆盖原先已捕获的常规姿态，不代表所有动态变色、缩放、混合、
粒子状态或工厂函数修改字体后的片尾均已补齐。物理 H1 的验证范围另记，
不使用主机测试结果宣称真机帧率。完整新资源尚不是已发布的 Release。
