# 领取奖励卡时的光效修复

用户反馈的是点击卡片领取的一瞬间。此前第二关的 33.92 / 36.52 FPS 测量只覆盖卡片掉在草坪上的首次出现与驻留，没有覆盖领取流程，不能用于证明领取动画流畅。

## 实际复现

`64dd50b6` 在 H1 真机通过普通触控领取樱桃炸弹奖励卡，三个约两秒窗口分别为 **6.29、1.46、1.47 FPS**，六秒平均 **3.16 FPS**。后续截图仍处于缓慢闪白阶段。这个失败记录不作为通过结果。

测量使用原生第二关末尾存档、普通触控、帧计数与单调时钟；第一段计时包含触摸 RPC，后两段只有端点读取。没有修改游戏 RAM 或计数来产生测试结果。失败测量结束后，通过匹配布局的原有 `mShutdown` 请求退出旧测试进程；这只是诊断清理，不作为动画完成或自然退出验收。

## 离线处理

领取使用的 `PARTICLE_SEED_PACKET_PICKUP` 对应 `particles/Award.xml`，包含多层旋转光芒、放大到 150 倍的加法光晕和独立透明闪光。此前只优化了加法绘图的临时内存，仍在每帧采样这些巨大粒子。

新增 `reward-effects.h1re`，将领取光效与星星爆发离线导出为 **212 帧、30 帧/秒**。动画仍按原有更新时钟推进，600 次更新的奖励过渡保持；采样不会缩短时长。像素按最终 LCD 密度生成，960×544 的源画布仅为移动中心留出屏幕外边缘，输出视口仍为 **480×272**，运行时不重新缩放图像。

连续加法层在电脑上合并，普通透明层保持独立顺序和原 `/256` 舍入。加法贡献按存储精度取整：相对原着色器的 RGB8 最终误差上限为 `[8,8,8]`。装饰性星星使用固定随机布局。正常透明层没有额外量化，不把这些结果称为所有随机布局、亚像素位置上的逐位相同。

资源磁盘大小 **934,748 字节**，开局前展开为 **1,220,539 字节**的内存帧容器，另申请 **30,328 / 4,891 字节**的两个复用缓冲。首帧提前展开，后续帧仅在已申请的缓冲中做 LZ4 字节复制解码与像素合成；不读盘、不申请内存、不执行粒子物理、旋转、缩放和纹理采样。进入奖励展示界面或重开关卡前释放；镜头和草坪入场完成、正式开玩前预载，继续已有存档时在继续弹窗前预载。文件缺失、损坏或不支持的颜色/变换状态回到原路径。

文字回放的 64 KiB 临时区从 BSS 移到普通堆，首次使用前申请、程序退出时释放，保留原有 128 KiB 私有栈和固件边界。

按原卡片飞向固定位置的曲线，离线裁掉所有可达视口之外的像素；运行时检查中心是否仍在预先计算的范围，越界即回退，不把不可见像素占用内存。未裁剪的 c806490a 因整包展开时 4 KiB 申请失败而回退到旧绘制，已拒绝交付。随后 4.6 MB 的完整展开版本也未通过预载；最终改为紧凑帧容器与双缓冲，并在所有资源 getter 返回后推进回收时点，让已不用的源纹理可以回收。

## 检查

- 原着色器与未量化的有序像素贡献：39 次整帧比较一致；在接入后的当前引擎重新导出，完整原始字节 SHA 相同。
- 实际资源解码与回放：全部 212 帧 × 六种位置/裁剪，共 **1,272 次整帧比较**，与独立参考一致；相对原图的最终 RGB8 误差不超上述界限。
- 缺失、截断、错误 CRC、坏帧索引、坏行偏移和非法 LZ 偏移共六种异常输入，均安全回退并释放内存。
- 原粒子更新被帧时钟替代；暂停、特殊颜色回退、星星结束和清理检查通过。
- 连续两次关卡预载、入场时不驻留、正式开玩前加载、奖励界面加载前释放与下一关重新加载通过。
- 临时区调整后的普通文字 720 次、矩阵文字 128 次、生成小图 288 次比较通过，相关失败回退和外部离线观察器检查保留。

上述是主机正确性检查。最终 `a50285db` 的真机普通触控领取四窗为 **18.78 / 15.58 / 12.07 / 0.00 FPS**；最后一窗包含同步加载领奖页。离线光效确实启用，回退计数和预载失败为零，领取/领奖阶段音频欠载为零，整个回归最终申请失败为零。此结果仍未达到 20 FPS，不能称为领取流畅。

GUI 保存 PC 采样显示，光效活动期间的 213 个有效采样中，显示提交占 56、草坪恢复占 38、烘焙光效占 29。全屏刷新和透明度零绘制的冗余已处理，当前仍有全屏复制与跨页加载开销。后续第三关入场/失败回归记录一次音频欠载，已如实保留。[原始记录](verification/reward-pickup/)包含旧失败和最终成品证据。

领奖音乐原本触发完整 XM 的约 5.01 MB 采样加载，现离线保留 1.67 MB 的原曲采样与原事件/编号。原版和裁剪版在 15 个播放位置、三种跳转、全部 30 个动态声道下比较 6,960,310 个采样一致。[音乐检查](verification/reward-pickup/host-award-music.json)。

## 生成

在新的输出目录中运行：

```powershell
python tools/build_host.py --widescreen --build-dir build/reward-compiler
python tools/tests/run_engine_probe.py --host build/reward-compiler --probe tools/tests/reward_effect_export.cpp --entry pvzh1_reward_effect_export --output build/reward-export
python tools/tests/run_engine_probe.py --host build/reward-compiler --probe tools/tests/reward_bounds_export.cpp --entry pvzh1_reward_bounds_export --output build/reward-bounds
python tools/pack_reward_effects.py --input build/reward-export/run/reward-effects.raw --bounds build/reward-bounds/run/reward-bounds.json
python tools/bake_file_index.py
```

资源来源、压缩前后哈希及生成器身份保存在 `provenance/offline-reward-effects.json`。部署先写资源和索引，再更新完整 BDA。个人存档只做本地备份，不进入仓库和安装包。
