# 植物僵尸 v0.1.0-beta.4

适用步步高 H1 / Y100 V1.41，480×272，中文触屏版。本版为 beta 预发布。

## 修复

- 修复从前两关连续游玩到第三关时，普通收集阳光、种植等动作触发的内存不足退出。预览图片与实战图片分阶段持有，缩小混音器工作区。
- 共享图片、菜单、战斗和开场数据按实际使用边界释放，退出时结束保存线程并清空应用分配。
- 修复保存线程扫描与前台释放之间的悬空读取窗口；已完成的存档副本由普通帧及时回收。
- 领奖光效使用可定位的离线帧和固定缓冲，保持完整 600 tick 动画，常驻内存约 1.26 MB → 55,708 字节。H1 直接分块读取，避免精简 newlib 无缓冲 fread 的逐字节读取。
- 进入领奖页即释放已结束战斗的动画库和草坪，卡片预览保留。真机本轮释放 3,950,999 字节。

## 安装

下载 Release 的 `H1PVZ-full-install.zip`：解压后将 `A/` 内程序复制到 H1 A 盘，将 `B/` 内完整资源目录复制到 B 盘。保留已有的 `B:/应用/数据/游戏/PVZ/userdata/`。程序也支持 A 盘资源；A 盘存在有效 PVZ 资源根目录时会优先使用 A 盘。

本版光效包格式升级，必须同时更新程序和资源，不能只替换 BDA。完整安装包不含个人存档。单独的 `H1PVZPortable.bda` 不含资源；下载校验文件为 `SHA256SUMS.txt`。

资源 2,674 个文件、166,759,394 字节，程序 3,759,940 字节；两者合计 170,519,334 字节，ZIP 下载大小以 Release 实际资产为准。光效取消整包外层压缩，磁盘增加 285,791 字节，以避免在普通战斗中持有整份展开数据。

## 验证范围

最终程序在 H1 上使用原版 V4 序列化器生成的 18 株植物第三关测试存档，从第 3 波正常游玩到通关；实际触摸收集、完整领奖、卡片显示、同进程第四关及选项、回菜单存档、创建和删除测试玩家、正常退出均通过。没有修改游戏 RAM 或写入获胜状态。

真机未出现内存分配失败和保存错误；5 笔后台任务完成并回收；删除回调 50 ms、首次界面显示 175 ms；退出后应用原生内存归零、保存线程移除，原始 5 文件存档恢复后读回 SHA-256 一致。18 株植物领奖活跃区间约 13.05 FPS，仍未达到全场景 20 FPS；没有重测全部关卡或数小时连续运行。

主机定向回归包括 20,000 次并发保存队列任务、真实文件失败恢复矩阵，以及全部 212 帧、1,272 组位置/裁剪的逐像素画面对比。CI 从固定 SDK 与已验证成品构建完整安装包，核验上传、下载及 Release 资产；不将打包称为重新编译或真机重测。
