# 启动文件查找优化

上一版冷加载耗时 9.25 秒，底层记录到 312 次原生打开、241 次打开失败；打开调用累计约 6.78 秒，实际读取约 5 MB 累计约 1.03 秒。这里采用本机校准的 40 Hz 时钟，单个 tick 为 25 ms，累计调用时间属于观测值。

新增 `resource-files.h1fi`，提前保存全部只读资源的文件名、长度和目录，启动时一次读取约 140 KiB。目录按规范化名称排序，查询使用二分查找。不在索引中的候选资源直接返回 `ENOENT`；存在的文件仍由原生文件系统打开，图片等文件仍校验实际文件头。

除了资源子目录，动画定义加载器还会先尝试根目录下的 `REANIM_*.h1a` / `.h1i` 等旧图片路径。这些只读图片候选也参与索引判断，避免继续触发不存在文件的 FAT 查找。

存档、日志等可变文件不参与索引，A/B 盘选择规则保持一致。索引缺失、截断或校验失败时使用原加载方式；程序修改受管理的资源文件或目录时，停用本次运行的索引。资源变更后须运行 `tools/bake_file_index.py` 重新生成索引及资源清单。

游戏、菜单与入场动画代码未改动；完整 450 次冒险更新仍保留。文件系统适配新增 6,864 项查找和格式检查，原生打开/查询函数的夹具覆盖存档绕过、A/B 盘、桶目录、失效与回退路径。
