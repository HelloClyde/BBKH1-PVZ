# H1 简体中文本地化

本次保留 480×272 宽屏、原版九列草坪、游戏规则和 V4 存档格式，中文图片与字体均在电脑端离线处理。

## 内容

- 1,121 个原有语言键全部提供中文内容，补充 17 个原先写死的界面键。制作人员姓名、商标和网址等专有内容保留原文。
- 157 个中文图片变体，包括主菜单石碑、欢迎木牌、选项/帮助/退出、游戏菜单、商店标识、准备/开始种植、僵尸纸条及头像页面。
- 20 套游戏字体覆盖 1,416 个所需非 ASCII 字形，共享 9 张离线 alpha 图集和 9 个 `.h1f` 紧凑尺寸表。实际显示某个字时才建立该字体的字形对象，避免给每套字体重复展开全部字符。保留原有拉丁字形宽度和基线，小号正文增加中文所需行高。
- 中文源图保持原有逻辑尺寸和 H1 存储尺寸；更新优先加载的 RGBA `.h1a` 以及对应 `.h1i`，避免仍显示旧英文版本。
- 中文 `properties/pvz-portable.xml` 最后载入，覆盖 `default.xml` 和代码中的按钮默认文案。
- 旧 V4 存档中的提示文本可能已经展开为英文。读档后仅转换一次，并在需要时重建动画文字的 UTF-8 字符索引；不增加每帧翻译工作，也不改变类布局或存档字段。

原图、文本、字体的固定来源与权利说明见 [NOTICE.md](../NOTICE.md)。

## 验证

使用实际引擎解析 20 套字体的 28,320 个字形组合，检查正宽度及真实图集矩形；检查普通提示与大波僵尸动画提示的旧档文本转换，保持原有显示时长且可重复调用。

共享表与完整描述的所有字形宽度、矩形、基线偏移及字体行高哈希相同（`b8d9bad91ec5369`）。主机完整流程的采样峰值从 30,525,588 降至 24,395,096 字节；这是主机内存观测，不替代 H1 真机内存结果。

字体遮罩保留离线 A8 字节，采样时直接使用 alpha，避免建立四倍大小的整张 ARGB 图集。A8 与原 ARGB 路径通过 240 次完整画面对比；结合共享尺寸表，主机流程采样峰值进一步降至 20,859,494 字节。H1 显示层的十字光标已关闭，触摸坐标、点击、选卡与种植预览仍由原游戏处理。

240 个完整画面的文字绘制缓存与原绘制路径逐像素一致，包含中英文、透明度、变化背景、裁剪和小数偏移；分配失败、缓存溢出与释放检查通过。主菜单 103 个离线片段通过 309 次原绘制对比与 103 次编码往返检查。

完整主机运行使用实际旧 V4 存档，通过种植、发射、命中、触摸暂停/恢复、领取第一关奖励和进入第二关。主机截图用于排版验收，不代表 H1 性能。图鉴截图使用原始图鉴类的单独主机排版夹具，不表示已在真机解锁所有植物。

H1 真机结果以 [final-native-verification.json](verification/final-native-verification.json) 的程序哈希、资源校验、帧率窗口和存档记录为准。旧英文版本的历史验证与当前中文版本区分保存。

## 重新生成

成品安装直接使用 `prebuilt/` 和 `private/resources-h1-wide/`。重新编辑中文时：

```powershell
python -X utf8 tools/build_zh_cn.py --output build/zh-cn/resources
python -X utf8 tools/build_host.py --build-dir build/host-zh-cn --widescreen --jobs 6
python -X utf8 tools/bake_selector.py --host-build build/host-zh-cn --prepared-source build/host-zh-cn/source --build-dir build/selector-bake-zh-cn --resources build/zh-cn/resources --output build/zh-cn/resources/h1menu/selector-wide.h1mb
python -X utf8 tools/tests/test_text_replay_engine.py --localization --host build/host-zh-cn --output build/zh-cn/engine-check --resources build/zh-cn/resources --bundle build/zh-cn/resources/h1menu/selector-wide.h1mb
python -X utf8 tools/tests/test_text_replay_engine.py --host build/host-zh-cn --output build/zh-cn/text-check --resources build/zh-cn/resources --bundle build/zh-cn/resources/h1menu/selector-wide.h1mb
```

修改语言或字体后重新烘焙菜单，再将验收通过的生成目录同步到运行资源目录并更新 `provenance/resources.json`；不能只替换文字而继续使用旧英文菜单包。构建 BDA 仍使用 `tools/build_widescreen.py`。H1 运行资源不含 OTF，运行时不执行字体栅格化或 PNG/WebP 解码。

资源生成结果在独立输出目录逐文件比较；图片、字体、XML、文本、元数据和菜单包均纳入比对。
