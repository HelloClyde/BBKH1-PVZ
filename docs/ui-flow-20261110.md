# 菜单、新建玩家与音量修复（2026-11-10）

## 改动

- 去掉主菜单同步玩家资料时的整套关卡资源预加载；进入关卡仍执行所需加载。菜单使用无损压缩的预烘焙素材，只展开当前播放的手部动画帧。
- 新建玩家和返回菜单时，把原有序列化结果交给后台文件写入任务，保留 V4 存档格式和临时文件／备份／原子替换流程。立即继续游戏会等待同一路径的待提交存档，避免读到旧状态。正常退出会等待写入完成、删除工作任务并恢复原中断回调。
- 选项加入音乐、音效触摸滑杆和百分比，首次默认均为 10%；正常退出后记住设置，下次启动恢复。
- 新玩家开场缓存改为 64 KiB 分页并检查分配失败，减少连续内存申请压力。首关退出问题曾实测为开场预读页分配失败。
