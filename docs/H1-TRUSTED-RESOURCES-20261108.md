# 可信资源与预览优化

安装后的只读资源按可信输入处理。CRC、Adler、目录内容哈希以及整包、整帧预检不再在游戏内执行；资源生成器和安装工具继续负责离线检查。读取文件头、索引和当前帧是播放本身需要的工作，文件读取、分配或解码失败仍会报错。

涉及动画页、字体缓存和字体瓦片、定义文件、菜单、开场视频、草坪、卡片光效、图片包和图片目录、文件目录、短音效包及加色查找表。定义文件只解码一次，不先完整校验再重读。字体瓦片目录在内存中只保留偏移，原来约 96 KiB 的连续分配缩为约 48 KiB。

大于 512 KiB 的动画压缩数据通过文件按页读取，不整包驻留。最后一个同类动画删除时释放其解码页；一次性动画还释放其缓存。关卡预加载依据当前关卡和仍存活的动画清理缓存，不因为启动时读过某种动画的定义就常驻它的离线帧。

发布用 `prebuilt/` 和最终原生验收记录仍保留上一已发布版本；完整新资源与新程序验收前，不以更新哈希的方式绕过发布检查。
